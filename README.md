# 🎧 Techno Events

Alle Techno-Events der Schweiz fürs Wochenende – mit Fahrzeit ab Beckenried (Auto & ÖV), Tickets mit Countdown, Tonight-Modus und Crew-Knöpfen für WhatsApp.

**App öffnen:** https://joerschi.github.io/techno-events/

## Dateien
| Datei | Inhalt |
| --- | --- |
| `index.html` | Die App (Design + Logik) |
| `events.json` | Events des Wochenendes + Ausblick (jeden Donnerstag automatisch aktualisiert) |
| `tickets.json` | Eigene Tickets |
| `venues.json` | Cache: Koordinaten & Fahrzeiten der Locations |
| `manifest.webmanifest`, `sw.js`, `icon-*.png` | Macht die Seite als App installierbar |
